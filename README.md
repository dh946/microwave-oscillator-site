# 光生微波文献排名（静态发布版）

公开访问地址： https://dh946.github.io/microwave-oscillator-site/

本仓库仅用于发布只读网页。GitHub Pages 只部署 `site/` 目录，包含网页和已核对的文献指标；不含论文 PDF、私有维护脚本或完整维护数据库。访客无需登录即可筛选与查看排名。

## 后续更新

在私有项目中通过本地网页添加 PDF、核对文献信息和指标后，告诉 Codex“同步上线”。Codex 会把更新后的网页数据同步到本仓库 `site/papers-data.js`；若页面代码也有变化，则同步 `site/index.html`。提交后 GitHub Actions 会自动重新发布，网址保持不变。

请勿将 PDF 上传到本仓库。
